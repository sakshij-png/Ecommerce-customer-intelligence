# E-Commerce Customer Intelligence & Retention Analytics

## Overview
ShopSphere is a Power BI dashboard project built to explore e-commerce sales performance, product categories, payment methods, regional activity, and customer segmentation.

## Objectives
- Monitor revenue, orders, customers, and average order value.
- Analyze revenue trends over time.
- Compare product category performance.
- Explore customer purchasing patterns using RFM segmentation.
- Identify customer-retention opportunities.
