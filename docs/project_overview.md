# Project Overview

## Project Name
E-Commerce Customer Intelligence & Retention Analytics

## Objective
To analyze e-commerce sales performance, customer purchasing patterns, product categories, payment methods, and customer retention opportunities using Power BI.

## Dataset
Brazilian E-Commerce Public Dataset by Olist.

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- Data modeling and visualization

## Key Features
- Revenue, order, customer, and average order value KPIs
- Monthly revenue trend analysis
- Product category performance
- Payment method distribution
- State-wise customer analysis
- RFM-based customer segmentation
- Customer retention recommendations

## RFM Analysis
RFM stands for Recency, Frequency, and Monetary value. It is used to group customers according to how recently they purchased, how frequently they ordered, and how much they spent.

## Learning Outcomes
- Importing and preparing datasets
- Creating relationships between tables
- Developing DAX measures and calculated columns
- Designing interactive dashboards
- Translating business questions into visual insights

## Project Status
Completed as a beginner portfolio project. Further improvements may include validating all metrics, refining customer segmentation, and adding deeper retention analysis.
